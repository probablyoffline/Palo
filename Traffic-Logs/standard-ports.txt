# standard-ports.txt
#
# Ports listed here must match what Palo Alto's application database officially
# defines as the standard port for the application — not just ports that are
# commonly used.
#
# Example: ssl/https runs on tcp-443 per Palo Alto's app-id. If a rule allows
# tcp-8443, that is non-standard regardless of how common it is in practice,
# because Palo Alto's application-default for ssl is tcp-443 only.
#
# If every port in an existing rule's service config appears in this file,
# the new App-ID rule uses application-default. If any port is absent, all
# ports are listed explicitly and the app-id-non-standard tag is added.
#
# Lines starting with # are comments. One entry per line.
# Format mirrors PAN-OS service member names (e.g. tcp-80, udp-53).
