# standard-ports.txt  v1.2.0
#
# Used in two ways by design-rule-apps.py:
#
#   Dynamic mode (default): supplement to Panorama's app-id database.
#     Entries here prevent false non-standard classifications for ports that
#     Panorama's predefined XML defines incompletely or not at all.
#
#   Static mode (--static-ports): primary reference for all port decisions.
#
# Two line formats are supported:
#
#   tcp-80            Global — treated as standard for ANY app observed on this port.
#                     Use for ports that legitimately carry many different apps
#                     (e.g. tcp-443 without SSL decryption).
#
#   msrpc:tcp-135     Per-app — treated as standard only for that specific app.
#                     Use for ports that should only ever carry one app's traffic.
#
# Format: protocol-port  (e.g. tcp-80, udp-53). One entry per line.
# Lines starting with # are comments.

# ── Per-app overrides ─────────────────────────────────────────────────────────
# tcp-135 is the RPC endpoint mapper — msrpc-base is a child of msrpc.
# Panorama defines the port on the parent entry only, not the child entry.
msrpc:tcp-135
msrpc-base:tcp-135
# RPC dynamic ports — Windows ephemeral range is standard for these apps.
# Ranges are supported as proto-LO-HI (e.g. tcp-49152-65535).
msrpc:tcp-49152-65535
msrpc-base:tcp-49152-65535
rpc:tcp-49152-65535
# udp-1434 is the SQL Server Browser service port (standard for mssql-mon).
